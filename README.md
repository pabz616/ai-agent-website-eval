# ai-agent-website-eval

OpenAI Agent
source - `https://www.kdnuggets.com/how-to-turn-a-python-script-into-an-ai-agent`

## GOAL

Learn how to build a simple agent using OpenAI and python

## SETUP

1. Start with a normal python script that performs a desired task.
2. Install an agent.
3. Set the agent to use the previously created script.
4. Make it recursive with a loop.

Run the website monitor from the repository root with:

```sh
uv run python scripts/ping_website.py
```
